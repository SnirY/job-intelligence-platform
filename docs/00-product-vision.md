# Product Vision

## Vision

Build a personal Job Search and Career Intelligence Platform that connects the jobs a user discovers with their real professional profile, resumes, projects, skill gaps, applications, and outcomes.

The product should become a personal career operating system rather than another job board.

## Core questions the product must answer

- Should I apply to this job?
- How well do I actually match?
- Which requirements are real blockers?
- What should I change in my resume?
- Which of my projects are most relevant?
- What should I learn next?
- Which project should I build or upgrade?
- Which job families respond to me best?
- Where in my application funnel am I struggling?
- What is the next best action?

## Core loop

```text
Discover Job
↓
Import Job
↓
Understand Job
↓
Compare With Career Profile
↓
Analyze Match & Gaps
↓
Recommend Action
↓
Tailor Resume
↓
Apply
↓
Track Result
↓
Learn From Outcome
```

Every job added should make the system smarter.

## Primary user

The first version is optimized for an active job seeker, especially junior, entry-level, graduate, intern, or career-transition candidates who:

- search across multiple sources
- have several projects and skills
- need to tailor resumes
- are unsure which gaps matter
- want a structured application workflow

The initial product is personal-first but must remain multi-user ready.

## Product differentiation

The product is not only:

- a job board
- an application tracker
- a resume builder
- an AI CV writer

Its differentiation comes from combining:

```text
Jobs
+
Career Profile
+
Evidence-Based Matching
+
Resume Intelligence
+
Skill Gap Analysis
+
Portfolio Strategy
+
Application Outcomes
```

## Long-term vision

Create a Personal Career Intelligence Platform that understands:

- where the user is now
- where they want to go
- what their observed target market requires
- which opportunities are most valuable
- which gaps matter most
- which actions are likely to improve their position

The long-term goal is for the system to answer:

> What should I do next, and why?
