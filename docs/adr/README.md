# Architecture Decision Records

Use this directory for significant, long-term architectural decisions.

Create an ADR when selecting or changing something such as:

- authentication provider
- task queue
- database strategy
- storage provider
- resume-rendering architecture
- major domain-model structure
- modular-monolith versus service boundaries

Suggested format:

```text
# ADR-XXX — Decision title

Status:
Proposed / Accepted / Superseded / Rejected

## Context

## Decision

## Consequences

## Alternatives Considered
```

Do not create ADRs for minor implementation details.
